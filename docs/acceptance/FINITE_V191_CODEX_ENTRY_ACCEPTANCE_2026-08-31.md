# Finite v191 — templates and Codex entry routes

Date: 2026-08-31  
Release marker: `hosted-release-marker-v191`

## Product correction

Finite now presents templates as a normal, useful starting route instead of qualifying or underselling them. The first page has four clear choices:

1. **Start fresh** — begin with the existing hints and optional fields.
2. **Start from a template** — choose a ready-made starting point and tailor it.
3. **Use Codex live** — Codex operates the real Finite interface collaboratively and pauses when the person's input matters.
4. **Watch live demo** — Codex runs a real Hobart template while the person advances only at visible Next gates.

## Codex handoff

Both Codex routes open a dedicated loading surface with one copy action. The copied setup points Codex at Finite's live page tools and establishes the intended interaction mode.

The live demo is not a video or simulation. It creates and develops real example state through Finite. Its Next control advances narration only; it never supplies plan approval, sensitive-data consent, or external authority.
